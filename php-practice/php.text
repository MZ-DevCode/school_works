mysqli_fetch_assoc() — возвращает строку результата в виде ассоциативного массива (доступ по именам колонок).

mysqli_fetch_array() — возвращает строку в виде массива с ассоциативными и числовыми ключами одновременно.

mysqli_fetch_row() — возвращает строку в виде числового массива (доступ только по индексам 0, 1, 2...).

mysqli_fetch_object() — возвращает строку в виде объекта (доступ к полям через стрелочку ->).

mysqli_num_rows() — возвращает количество строк, полученных в результате выполнения SQL-запроса.

mysqli_affected_rows() — возвращает количество строк, затронутых последним запросом изменения данных (INSERT, UPDATE, DELETE).
